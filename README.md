# Próg demo

Klikalne demo aplikacji „Próg” (mieszkania na udziały). Jeden plik: `public/index.html`.
Wszystkie mieszkania, ceny i transakcje są zmyślone lub symulowane.

## Wdrożenie na Render

1. Render → New → Blueprint → wybierz to repozytorium → Apply.
2. Po chwili strona działa pod adresem `prog-demo-….onrender.com`.
3. Każdy commit do gałęzi głównej wdraża się automatycznie.
